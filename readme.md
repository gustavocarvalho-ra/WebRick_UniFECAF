# Rick and Morty Explorer

Projeto acadêmico desenvolvido utilizando HTML5, CSS3 e JavaScript,
com integração à Rick and Morty API.

## Sobre o projeto

O Rick and Morty Explorer é uma aplicação web que permite
explorar personagens da série Rick and Morty.

As informações são obtidas dinamicamente através de uma API pública,
permitindo visualizar nome, imagem, status, espécie, gênero e origem
dos personagens.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Fetch API
- Rick and Morty API

## Funcionalidades

- Listagem dinâmica de personagens.
- Pesquisa de personagens pelo nome.
- Filtro por status.
- Carregamento de mais personagens.
- Interface responsiva.

## API utilizada

Documentação oficial:
https://rickandmortyapi.com/documentation

Endpoint:
https://rickandmortyapi.com/api/character

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta no Visual Studio Code.
3. Execute o arquivo index.html utilizando o Live Server.
4. Aguarde o carregamento dos personagens.

## Objetivo acadêmico

Projeto desenvolvido como atividade acadêmica para demonstrar
conhecimentos em HTML, CSS, JavaScript, manipulação do DOM
e consumo de APIs utilizando Fetch.
